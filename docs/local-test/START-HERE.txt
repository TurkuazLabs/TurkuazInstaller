TURKUAZINSTALLER COMMUNITY — LOCAL TEST ONLY / UNSIGNED
=========================================================

IMPORTANT: The GitHub Actions artifact contains ANOTHER ZIP.
Step 1: Download the GitHub Actions artifact named
        TURKUAZINSTALLER-TEST-ONLY-UNSIGNED-win-x64.
Step 2: Extract the outer ZIP.

        and EXTRACT THIS SECOND ZIP into a fresh test folder.

  TurkuazInstaller.Bootstrapper.exe     <-- Windows GUI entrypoint

    (keep ALL adjacent DLL/native/runtime files here)

    (keep ALL adjacent DLL/native/runtime files here)

Do not double-click either ZIP as if it were an installer.
Do not move the Bootstrapper.exe out of its extracted root folder.
Run only on a disposable Windows 10 (1809+) or Windows 11 x64 test VM.
This unsigned file can be blocked by Windows SmartScreen/antivirus.
DO NOT disable protections or force an exception to run it.

If Windows permits execution, run TurkuazInstaller.Bootstrapper.exe.
It is a launcher, not a Setup wizard, and may close after starting the
separate WinUI GUI. The app/ and cli/ folders MUST stay alongside it.

If it does nothing: check Event Viewer -> Windows Logs -> Application
for faults naming TurkuazInstaller.Bootstrapper.exe or WinUI.exe.
Send the error text or a screenshot. You may also open PowerShell in
this extracted folder and run Diagnose-LocalTest.ps1 if your standard
PowerShell execution policy permits it; DO NOT relax your policy.
The diagnosis script only checks files, versions and signatures and
does not run any unsigned executable.

A green compilation/packaging CI does not yet prove this GUI will
start on every user's Windows build. A signed release is REQUIRED
before ordinary end-user installation or distribution.

 
## Silent startup on Windows

`TurkuazInstaller.Bootstrapper.exe` is a Windows-subsystem bootstrapper;
double-clicking it does **not** create a console. If the initial checks fail,
the previous build returned a numeric exit code without any visible error.
The new local test build records non-sensitive diagnostic results at
`%LOCALAPPDATA%\TurkuazInstaller\logs\bootstrap-startup.log`. An
`HANDOFF_RETURNED exit=0` entry means the bootstrapper accepted the
handoff, **not** that WinUI displayed a usable window. If the
desktop failed later, inspect Windows Event Viewer → Windows Logs →
Application for `TurkuazInstaller.WinUI.exe` faults.

The hosted Windows distribution CI verifies the ZIP layout, launches
the bootstrapper, and requires a NEW WinUI main window handle plus the
MainWindowReady stage from that SAME process ID. CI fails closed if the
window or readiness record is missing and collects Windows Application
event diagnostics. This is still not a guarantee of UI
compatibility on every Windows build. Do not disable SmartScreen or
AV/security protections to run unsigned archives.
