# Roadmap

## v0.1.0 - Foundation
Domain, Contracts, Application, Infrastructure, WinUI 3 MVVM shell, tests ve CI.

## v0.2.0 - Native Bootstrapper
HTTPS bootstrap manifest, x64/ARM64 tespiti, runtime indirme ve dogrulama.

## v0.3.0 - Installer UI
Product branding, durum bazli install/update ekranlari, progress ve release notes.

## v0.4.0 - Package Security
Resume download, SHA-256, Authenticode ve staging.

## v0.5.0 - Installation Engine
Install, uninstall, shortcut, process detection ve installation state.

## v0.6.0 - Update Engine
Full update, delta provider kontrati ve stable/beta channel.

## v0.7.0 - Reliability
Repair, transactional apply, health check ve rollback.

## v0.8.0 - Prerequisites
.NET, VC++ Runtime, WebView2 ve reboot handling.

## v0.9.0 - Release Sources
GitHub, Gitea ve generic HTTPS.

## v0.10.0 - Operations
CLI, silent install ve diagnostics.

## v0.11.0 - Pro Extension Contracts
Private feed, license/device authorization ve staged rollout.

## v0.12.0 - JHoster Pilot
Gercek install/update/repair/rollback testi.

## v1.0.0
Production Community release.
